# Exercícios de Lógica de Programação com JavaScript e React

Este repositório reúne os exercícios que estou desenvolvendo a partir do livro **"Lógica de Programação e Algoritmos com JavaScript: uma Introdução à Programação de Computadores com Exemplos e Exercícios Para Iniciantes"**, de **Edécio Fernando Iepsen**.

O objetivo deste projeto é fortalecer minha base em **lógica de programação**, praticando a resolução de problemas através de **algoritmos implementados em JavaScript** e explorando aplicações desses conceitos dentro do ecossistema **React**.

## 📚 Sobre o Livro

O livro apresenta os fundamentos da lógica de programação utilizando **JavaScript** como linguagem principal.  

Durante os capítulos, são abordados conceitos essenciais para quem está iniciando no desenvolvimento de software, como:

- Construção de **algoritmos**
- Estruturas de **decisão**
- Estruturas de **repetição**
- Manipulação de **variáveis**
- Entrada e saída de **dados**
- Resolução de **problemas computacionais**

Os exercícios propostos no livro ajudam a desenvolver o **raciocínio lógico necessário para programar**, independentemente da linguagem utilizada.
